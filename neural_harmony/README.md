## 🦢 О ПРОЕКТЕ

**NEURAL_HARMONY** - это революционная корпоративная социальная платформа, созданная **NEURAL_ARCHITECT_PREMIUM++** для трансформации рабочей среды. Наша миссия - снять стресс сотрудников через привычные социальные действия, улучшить моральный дух компании и повысить работоспособность через информативно-развлекательный подход.

### Ключевые особенности:
- 🎨 Стиль ВКонтакте с расширенным функционалом
- 🤖 ИИ-аналитика и умные боты
- 📱 Полная мобильная адаптация
- 🎮 Онлайн-игры между сотрудниками
- 🎤 Голосовые сообщения и медиа-контент
- ✏️ Рисование на стене
- 👥 Группы и сообщества
- 💼 Расширенный личный кабинет
- 🔐 Ролевая система доступа
- 🌐 API для интеграции

## 🚀 БЫСТРЫЙ СТАРТ

### Требования
- Node.js 18+
- MongoDB 6+
- Redis 7+
- FFmpeg
- Git

### Установка

```bash
# Клонирование репозитория
git clone <repository-url>
cd neural_harmony

# Установка зависимостей
npm install

# Настройка переменных окружения
cp .env.example .env
# Отредактируйте .env файл

# Запуск базы данных
mongod --config /etc/mongod.conf

# Запуск Redis
redis-server

# Запуск сервера
npm start

# Для разработки
npm run dev
```

### Переменные окружения (.env)

```env
# Server
PORT=3000
NODE_ENV=development

# Database
MONGODB_URI=mongodb://localhost:27017/neural_harmony
REDIS_URL=redis://localhost:6379

# Security
JWT_SECRET=your-super-secret-jwt-key
BCRYPT_ROUNDS=12

# File Upload
MAX_FILE_SIZE=104857600
UPLOAD_PATH=./public/uploads

# AI Services
OPENAI_API_KEY=your-openai-api-key
TENSORFLOW_MODEL_PATH=./models

# Email
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-password

# External APIs
GOOGLE_API_KEY=your-google-api-key
TWILIO_SID=your-twilio-sid
TWILIO_TOKEN=your-twilio-token

# Logo
LOGO_TEXT="NEURAL_ARCHITECT_PREMIUM++"
LOGO_SYMBOL="🦢"
```
